# OpenRotMG client

Realm of the Mad God **123.5.1** client, running through Ruffle.

Requires Python 3. Run `./run.sh` on Linux/macOS or `.\run.bat` on Windows.

The command downloads a verified Ruffle release, caches it locally, and starts the client web server at http://127.0.0.1:18923/ .

The game backend is not started yet. The loading scene works; the retry error is expected until an account server exists.
